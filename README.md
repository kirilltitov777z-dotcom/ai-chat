# LotiChat (Material You)

Мобильный веб-чат с ИИ на **бесплатных моделях** (DeepSeek и другие через OpenRouter).
Работает онлайн, ставится на телефон как приложение (PWA). Тайм-аутов нет — ответ приходит стримом.

## Онлайн
Открой ссылку GitHub Pages (смотри в описании репозитория) → в Chrome: меню → **«Добавить на главный экран»**.

## 📱 APK (андроид-приложение)
Сборки лежат в разделе Releases: **[Скачать AI-Chat.apk](https://github.com/kirilltitov777z-dotcom/ai-chat/releases/download/apk/AI-Chat.apk)** (~5 МБ, не «артефакт», а готовый файл).
Установка: скачай → нажми на файл → «Установить» (разреши установку из неизвестных источников — это норма для APK вне магазина).
Пересборка: GitHub → вкладка Actions → build-apk → Run workflow.

## Как получить БЕСПЛАТНЫЙ ключ (OpenRouter)
1. Зайди на **openrouter.ai** (Google-аккаунтом — 30 секунд).
2. Профиль → **Keys** → **Create key** → скопируй.
3. В приложении: ⚙️ Настройки → провайдер «OpenRouter» → вставь ключ → «Проверить ключ и загрузить модели».
4. Выбери бесплатную модель (помечена `:free`, например `deepseek/deepseek-chat-v3-0324:free`).

Платный официальный DeepSeek: ключ с platform.deepseek.com → провайдер «DeepSeek API».

## Что умеет
- 💬 Чат со стримингом ответа, стоп-кнопка, ↻ перегенерация
- 📷 **Фото с камеры** прямо в чате + 🖼 фото из галереи + 📎 файлы (текст до 64 КБ) + вставка через 🔥 Ctrl+V
- 🧠 Показ «мышления» у reasoning-моделей
- 💾 История чатов в памяти телефона, много чатов, экспорт/импорт JSON
- 🎨 Material You: тёмная/светлая/авто тема, 6 цветов акцента
- ⚙️ Свой промпт (характер бота), температура, свой OpenAI-совместимый сервер (LM Studio, Ollama)
