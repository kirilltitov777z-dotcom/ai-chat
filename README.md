# LokiChat 1.0

Бесплатный ИИ-чат для Android. Нативное приложение на Kotlin + Jetpack Compose (Material You 3).

## Что умеет
- 💬 Чат со стримингом ответов, остановка, повтор ответа
- 🆓 Работает **сразу без API-ключа** (Pollinations / gpt-oss-20b)
- 🧠 Режим мышления и поиск в интернете (Wikipedia + DuckDuckGo)
- 📷 Камера, галерея, файлы — вложения в сообщение
- 👤 Аккаунт: логин + пароль, переписка сохраняется за аккаунтом
- 🎨 Material You 3: цвета системы, тёмная/светлая тема, 6 акцентов
- 🔧 Свой DNS-резолвер (IPv4 + DoH) — работает даже если телефон не резолвит IPv6-хосты

## Установка
Скачай APK → установи (разреши «неизвестные источники»).

Direct: https://github.com/kirilltitov777z-dotcom/ai-chat/releases/download/apk/LokiChat.apk

## Провайдеры
| Провайдер | Ключ | Примечание |
|---|---|---|
| **Бесплатно (без ключа)** | не нужен | Pollinations, лимит 1 ответ в 45 сек |
| Groq | нужен | console.groq.com/keys, очень быстро |
| OpenRouter | нужен | openrouter.ai/keys, много :free моделей |
| Свой сервер | — | LM Studio, Ollama, vLLM |

## Режим разработчика
